# 🧸 小念桌宠

一只会从对话框里爬出来、趴在屏幕上的小熊。

## 她会什么
- 悬浮窗桌宠：单击/双击/长按/甩飞/连击3-5-8
- 感知：前台App（开抖音就吃醋）、截图（摆pose）、充电/低电量
- 碎念：每小时换一句，喝水提醒，孤独递进5-30分钟
- 云端：Supabase 同步（大脑遥控身体）

## 安装（全程手机，不需要电脑）
1. 等 Actions 构建完成，进仓库 Actions 页下载 xiaonian-pet-apk
2. 安装 APK（允许未知来源）
3. 打开 app，依次开启：悬浮窗 / 使用情况访问 / 通知 / 电池白名单
4. 点「让小念出来」

## 配置
`assets/xiaonian-config.json`：词池、App反应、后端地址（supabase_url/anon_key 填好后大脑就能遥控身体）
